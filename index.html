Step 01

GitHub Account তৈরি করুন

GitHub হলো এমন একটি platform যেখানে আপনার code, file এবং project repository আকারে রাখা যায়। PocketHost Studio আপনার GitHub account-কে hosting storage হিসেবে ব্যবহার করবে।

1

GitHub খুলুন

GitHub.com এ যান এবং Sign up চাপুন।

2

Email ও Password দিন

আপনার নিজের email address ব্যবহার করুন এবং একটি শক্তিশালী password সেট করুন।

3

Verification সম্পন্ন করুন

GitHub যে verification/email confirmation চাইবে তা সম্পন্ন করুন।

💡 Username মনে রাখুন: আপনার GitHub username পরে Live URL তৈরিতে প্রয়োজন হবে। যেমন halalcodes।
Step 02

Hosting-এর জন্য Repository তৈরি করুন

Repository হলো আপনার hosting storage-এর মতো। এখানে PocketHost আপনার File, Image এবং HTML content রাখবে।

1

New Repository চাপুন

GitHub profile → Repositories → New নির্বাচন করুন।

2

একটি নাম দিন

যেমন my-host বা pockethost-files।

3

Public নির্বাচন করুন

GitHub Pages দিয়ে সরাসরি public content serve করতে চাইলে Repository-টি Public রাখা সবচেয়ে সহজ পদ্ধতি।

4

Create Repository

সবশেষে Create repository চাপুন।

⚠️ গুরুত্বপূর্ণ: এই Repository-তে এমন কোনো ব্যক্তিগত বা গোপন তথ্য রাখবেন না যা public হয়ে গেলে সমস্যা হতে পারে।
Step 03

GitHub Pages চালু করুন

GitHub Pages আপনার Repository-এর static file-কে একটি Live Website URL-এ প্রকাশ করে।

1

আপনার Repository খুলুন।

2

Settings → Pages এ যান।

3

Build and deployment-এর Source হিসেবে Deploy from a branch নির্বাচন করুন।

4

Branch হিসেবে সাধারণত main এবং Folder হিসেবে / (root) নির্বাচন করুন।

5

Save চাপুন। GitHub কিছু সময়ের মধ্যে আপনার Pages URL তৈরি করবে।

🌐 সাধারণ URL pattern: https://USERNAME.github.io/REPOSITORY/
Step 04

Personal Access Token তৈরি করুন

PocketHost Studio আপনার হয়ে Repository-তে File তৈরি, পরিবর্তন ও মুছে ফেলার জন্য GitHub API ব্যবহার করে। এজন্য একটি access token প্রয়োজন।

1

GitHub → আপনার Profile Picture → Settings এ যান।

2

Developer settings খুলুন।

3

Personal access tokens → Tokens (classic) নির্বাচন করুন।

4

Generate new token (classic) নির্বাচন করুন।

5

Token-এর একটি Note দিন এবং প্রয়োজন অনুযায়ী expiration নির্বাচন করুন।

6

repo scope নির্বাচন করুন।

7

Generate token চাপুন এবং Token একবারই দেখানো অবস্থায় নিরাপদ জায়গায় রাখুন।

🔐 সবচেয়ে গুরুত্বপূর্ণ নিরাপত্তা নিয়ম:
Token কখনো কাউকে পাঠাবেন না, GitHub Repository-তে লিখবেন না, HTML/JS source code-এর ভিতরে স্থায়ীভাবে রাখবেন না এবং Screenshot-এ প্রকাশ করবেন না। Token ফাঁস হয়ে গেলে GitHub Settings থেকে সেটি revoke/delete করে নতুন token তৈরি করুন।

FAQ

সাধারণ প্রশ্ন

GitHub একদম না জানলে কি PocketHost ব্যবহার করতে পারব?

হ্যাঁ। এই Landing Page-এর Beginner Guide অনুসরণ করে প্রথমবার Account, Repository, Pages এবং Token সেটআপ করা যাবে।

আমার কি আলাদা Hosting কিনতে হবে?

PocketHost-এর মূল hosting workflow GitHub Repository ও GitHub Pages ব্যবহার করে, তাই আলাদা hosting server প্রয়োজন হয় না। GitHub-এর নিজস্ব limits, policies ও availability প্রযোজ্য।

মোবাইল ফোন দিয়ে কি সবকিছু করা যাবে?

হ্যাঁ, PocketHost Studio mobile-friendly এবং GitHub-এর mobile web interface ব্যবহার করেও প্রয়োজনীয় setup করা যায়।

একাধিক Repository কেন ব্যবহার করব?

বিভিন্ন project বা hosting content আলাদা রাখতে এবং আপনার GitHub usage পরিকল্পনা অনুযায়ী একাধিক Repository ব্যবহার করতে পারেন।

Token কোথায় রাখব?

PocketHost-এর Settings-এ প্রয়োজন অনুযায়ী Token ব্যবহার করুন। Shared/public device-এ Token save না করাই নিরাপদ। Token কখনো source code-এ লিখবেন না।

Upload করার পর সঙ্গে সঙ্গে Link কাজ না করলে?

GitHub API commit সম্পন্ন হওয়া এবং GitHub Pages update হওয়ার জন্য কিছু সময় লাগতে পারে। কিছুক্ষণ অপেক্ষা করে Reload করুন।

আমি কি যেকোনো File Host করতে পারব?

PocketHost মূলত static hosting ও GitHub Repository content management-এর জন্য। GitHub-এর file size, repository, Pages এবং policy limitations প্রযোজ্য।
